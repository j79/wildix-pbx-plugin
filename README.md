# wildix-tools — catalogue de plugins Claude

Dépôt privé contenant le plugin **wildix-pbx** : interroger et administrer n'importe quel PBX Wildix et les services cloud Wildix via leurs API REST, avec une référence API embarquée (mise à jour à partir de docs.wildix.com).

## Installation

Dans Claude, ajoutez ce dépôt comme source de plugins (`owner/wildix-pbx-plugin`), puis installez **wildix-pbx**. Les nouvelles versions publiées ici vous parviennent automatiquement.

Prérequis : avoir accès à ce dépôt privé (invitation du propriétaire).

## Mises à jour

Une tâche planifiée vérifie chaque vendredi la documentation des API Wildix. Une nouvelle version n'est proposée que si des routes ont été **ajoutées** ; les routes retirées de la documentation sont conservées et marquées *deprecated*. Chaque proposition arrive sous forme de demande de fusion (pull request) validée par le propriétaire avant publication.
