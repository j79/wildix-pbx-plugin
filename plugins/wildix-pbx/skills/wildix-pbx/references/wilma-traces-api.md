### Traces

#### `GET` `/v2/traces`

Queries traces newest first. Filter by service, status, time range, text
    or indexed trace attributes. Results contain trace summaries without
    spans.

- operationId: `QueryTraces`
- **Scopes**: `wilma-traces:QueryTraces`, `wilma-traces:read`
- **Parameters**
  - `company` (query) — string _(minLen=3; maxLen=30)_
  - `service` (query) — string
  - `status` (query) — string — Current resource state. Complete is not immutable: a long-lived trace may transition from complete back to pending when new work is appended, then complete again. _(enum: `complete`, `complete_with_errors`, `error`, `pending`)_
  - `from` (query) — string — Inclusive start of the window on the trace's startTime: an ISO-8601 instant with its offset (`2026-07-10T14:12:30.123Z`, `2026-07-10T16:12:30+02:00`) or a date `YYYY-MM-DD`, read as midnight UTC. Any other spelling, or a `from` later than `to`, is a 400.
  - `to` (query) — string — Exclusive end of the window on the trace's startTime, in the spelling `from` takes: the window is `[from, to)`.
  - `search` (query) — string — Case-insensitive substring, at most 128 characters, of the trace id or one of these Trace.attributes (span and message content is not searched): session.id, session.traceId, user.id, user.name, model, tool.callId, call.id, call.caller.name, call.caller.number, call.dialed, agent.id, agent.name, automation.id, automation.name, task.id, tool.id, tool.name, skill.id, skill.name, sandbox.id, conversation.id, profile.id, profile.name. A longer term is a 400.
  - `limit` (query) — number _(min=1; max=100)_
  - `cursor` (query) — string — Opaque cursor returned by a previous page; pass it back to fetch the next page. _(minLen=1; maxLen=2048)_
  - `filter` (query) — array — Trace filters, one per entry; a trace matches when every entry holds. - `key=value`: the Trace.attributes value equals `value`, e.g. `filter=channel%3Dvoice`. - `key=*`: the attribute is present with a non-empty value, e.g. `filter=call.transferTo%3D*`. - `metric>=N` / `metric<=N`: an inclusive bound on a Trace.metrics value, e.g. `filter=durationMs%3E%3D60000`; both bounds on one metric give a window. A trace that carries no value for the metric matches no bound, so `usage.interruptions<=0` does not find a trace that never recorded it. `durationMs` is the trace's own wall-clock length: every ended trace has it, a pending one never does. `*` always means presence, so a literal `*` value cannot be matched; `key=` matches an empty value; when one key is given twice, the last entry wins. `N` is a plain decimal (`-12`, `0.5`) within ±9007199254740991 (2^53−1). Any other entry is a 400 ValidationException that names it: an empty entry, one with no `=`, one with nothing before `=` (`=x`), a reversed bound (`durationMs=>N`), strict `>` or `<`, a bound on a name that is not a trace metric, `key=value` on a metric name (bound it with `>=`/`<=` instead), and an `N` that is not a plain decimal (`0x10`, `1e3`) or lies outside that range.

#### `GET` `/v2/traces/items/{traceId}/model-calls/{spanId}`

Returns the exact request one model call of a session trace was sent, and what the model
    answered: the system prompt, every message, the tools offered with their definitions, the
    tool choice and the settings. Read from the conversation history the session archived, so
    nothing is clamped; files are described, never returned.

    NotFound names the reason in its message with one of these phrases, which clients may match:
    - `own model calls`: the span is not one of the session's own model calls.
    - `before model requests were recorded`: the call predates request recording.
    - `no longer archived`: the archived history it was sent is no longer kept.

- operationId: `GetModelCall`
- **Scopes**: `wilma-traces:GetModelCall`, `wilma-traces:read`
- **Parameters**
  - `traceId` (path) — string **(required)** — Opaque trace identifier generated by the tracing runtime. _(minLen=1; maxLen=128)_
  - `spanId` (path) — string **(required)** — The `llm.call` span's id, as `GetTrace` returns it. _(minLen=1; maxLen=128)_
  - `company` (query) — string _(minLen=3; maxLen=30)_
- **Response 200** (`GetModelCallResponseContent`)
  - `modelCall` — ModelCall **(required)** — One model request as the model was sent it, and its answer.
    - `system` — string — The system prompt, with the step-limit notice when `stepLimitReached`. Absent when no turn recorded it.

      - _array of_ `ModelCallMessage`
        - `role` — string **(required)** _(enum: `system`, `user`, `assistant`, `tool`)_
        - `kind` — string **(required)** — Where a message came from, beyond its role. _(enum: `message`, `turn_context`, `steer`, `summary`, `interruption`, `assistant`, `tool`)_
        - `parts` — array **(required)**

            - `input` — any — `tool-call`: the arguments the model wrote.
            - `outputType` — string — `tool-result`: the AI SDK output type, e.g. `text`, `json`, `error-text`, `error-json`, `content`, `execution-denied`.
            - `output` — any — `tool-result`: the output as the model read it. Text and JSON whole; for `content`, a list of `{type: 'text', text}` and `{type: 'file', mediaType?, filename?}`; absent for other output types. A `json` or `text` result without `output` was `null`.

        - `providerToolId` — string — A provider-executed tool's id, e.g. `openai.web_search`.
        - `args` — any — A provider-executed tool's arguments.
    - `toolChoice` — string — `auto`, `required`, `none` or `tool:<name>`; absent for the provider default.

### Usage

#### `GET` `/v2/traces/metrics`

Aggregates span-level metrics from traces. QueryUsage answers session-level questions
    (how many sessions, what AI cost); QueryMetrics answers per-entity funnels inside them:
    filter spans by name and attribute equality, bucket by time, group by span attribute keys
    and sum the spans' numeric attributes plus a `spans` count of matching spans.

    Examples: copilot per-resource funnels (spans asset.shown / asset.seen / action.clicked
    grouped by asset.id — emitted vs seen vs clicked), per-tool usage of agents, per-skill
    usage of assistants.

- operationId: `QueryMetrics`
- **Scopes**: `wilma-traces:QueryMetrics`, `wilma-traces:read`
- **Parameters**
  - `company` (query) — string _(minLen=3; maxLen=30)_
  - `service` (query) — string
  - `name` (query) — array — Span names to aggregate, e.g. asset.shown. Multiple names aggregate together; group by `name` to split them.
  - `from` (query) — string — Inclusive start of the window on the span's startTime: an ISO-8601 instant with its offset (`2026-07-10T14:12:30.123Z`, `2026-07-10T16:12:30+02:00`) or a date `YYYY-MM-DD`, read as midnight UTC. Defaults to 30 days before `to`. Any other spelling, or a `from` later than `to`, is a 400.
  - `to` (query) — string — Exclusive end of the window, in the spelling `from` takes: the window is `[from, to)`. Defaults to now.
  - `interval` (query) — string — Time bucket size. Omit for one row per group over the whole range. _(enum: `hour`, `day`, `week`, `month`, `total`)_
  - `groupBy` (query) — array — Span attribute keys to group by (e.g. `asset.id`, `automation.id`), plus the reserved key `name` for the span name. A key that is neither `name` nor a declared trace attribute is a 400.
  - `limit` (query) — number _(min=1; max=100)_
  - `cursor` (query) — string — Opaque cursor returned by a previous page; pass it back with the same `groupBy`. A cursor from another grouping, or one altered, is a 400. _(minLen=1; maxLen=2048)_
  - `filter` (query) — array — Span filters, one per entry, in the QueryTraces grammar. `key=value` matches a span attribute exactly, e.g. `filter=asset.id%3Dasset-1&filter=channel%3Dcalls`; a span inherits its trace's attributes, so a trace-level key narrows spans too. `key=*` keeps spans where the attribute is present. `metric>=N` / `metric<=N` bound the span's own metrics, not its trace's: a span carries `durationMs` and its `usage.*` counters only, so a bound on any other metric (`spans`, `spans.errors`, `latency.*`) is a 400. An entry outside the grammar is a 400 ValidationException naming it, as QueryTraces describes.
- **Response 200** (`QueryMetricsResponseContent`)
  - `rows` — array **(required)**
    - _array of_ `UsageRow`
      - `bucket` — string — Start of the time bucket; absent when interval is 'total'.
      - `dimensions` — DimensionsMap
        - _map of_ `string`
      - `metrics` — MetricsMap **(required)** — Expandable numeric aggregates.
        - _map of_ `number`
  - `total` — MetricsMap **(required)** — Expandable numeric aggregates.
    - _map of_ `number`
  - `nextCursor` — string — Opaque cursor returned by a previous page; pass it back to fetch the next page. _(minLen=1; maxLen=2048)_
- Errors: `400`

#### `GET` `/v2/traces/usage`

Aggregates usage from traces. For conversational services one trace is
    one logical session, so 'sessions' is the distinct trace count and
    'usage.cost' is summed once per trace. Results can be bucketed by time and
    grouped by indexed Trace.attributes such as agent.id, channel and
    user.id.

- operationId: `QueryUsage`
- **Scopes**: `wilma-traces:QueryUsage`, `wilma-traces:read`
- **Parameters**
  - `company` (query) — string _(minLen=3; maxLen=30)_
  - `service` (query) — string
  - `from` (query) — string — Inclusive start of the window on the trace's startTime: an ISO-8601 instant with its offset (`2026-07-10T14:12:30.123Z`, `2026-07-10T16:12:30+02:00`) or a date `YYYY-MM-DD`, read as midnight UTC. Defaults to 30 days before `to`. Any other spelling, or a `from` later than `to`, is a 400.
  - `to` (query) — string — Exclusive end of the window, in the spelling `from` takes: the window is `[from, to)`. Defaults to now.
  - `interval` (query) — string _(enum: `hour`, `day`, `week`, `month`, `total`)_
  - `groupBy` (query) — array — Trace attribute keys to group by, e.g. `agent.id`, `channel`. A key that is not a declared trace attribute is a 400.
  - `limit` (query) — number _(min=1; max=100)_
  - `cursor` (query) — string — Opaque cursor returned by a previous page; pass it back with the same `groupBy`. A cursor from another grouping, or one altered, is a 400. _(minLen=1; maxLen=2048)_
  - `filter` (query) — array — Trace filters, one per entry, in the QueryTraces grammar: `key=value` for an exact Trace.attributes value (e.g. filter=agent.id%3Dsupport-agent&filter=channel%3Dvoice), `key=*` for a present attribute, `metric>=N` / `metric<=N` for an inclusive bound on a Trace.metrics value. Only the traces that match are summed. An entry outside that grammar is a 400 ValidationException naming it, as QueryTraces describes.
- **Response 200** (`QueryUsageResponseContent`)
  - `rows` — array **(required)**
    - _array of_ `UsageRow`
      - `bucket` — string — Start of the time bucket; absent when interval is 'total'.
      - `dimensions` — DimensionsMap
        - _map of_ `string`
      - `metrics` — MetricsMap **(required)** — Expandable numeric aggregates.
        - _map of_ `number`
  - `total` — MetricsMap **(required)** — Expandable numeric aggregates.
    - _map of_ `number`
  - `nextCursor` — string — Opaque cursor returned by a previous page; pass it back to fetch the next page. _(minLen=1; maxLen=2048)_
- Errors: `400`
