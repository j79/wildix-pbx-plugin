### Audit

#### `GET` `/v2/audit/events`

Queries immutable audit events newest first. Filter by resource URI (exact
    or prefix), actor, action, time range or indexed event attributes. Results
    carry enough data to render a resource history view.

- operationId: `QueryAuditEvents`
- **Scopes**: `wilma-audit:QueryAuditEvents`, `wilma-audit:read`
- **Parameters**
  - `company` (query) — string _(minLen=3; maxLen=30)_
  - `uri` (query) — string — Only events about this exact resource, e.g. 'wilma://agents/UXDT1W9fI3sj'. Mutually exclusive with uriPrefix. _(pattern=^[a-z][a-z0-9+.-]*://.+$; minLen=1; maxLen=512)_
  - `uriPrefix` (query) — string — Only events whose resource URI starts with this prefix, e.g. 'wilma://agents/' for every agent event or 'wilma://' for every Wilma resource. Mutually exclusive with uri. _(pattern=^[a-z][a-z0-9+.-]*://.*$; minLen=1; maxLen=512)_
  - `action` (query) — string
  - `actorId` (query) — string — Filter by the user, API key or service that performed the action.
  - `actorType` (query) — string _(enum: `user`, `api_key`, `service`)_
  - `from` (query) — string — ISO-8601 timestamp with millisecond precision, e.g. '2026-07-10T14:12:30.123Z'.
  - `to` (query) — string — ISO-8601 timestamp with millisecond precision, e.g. '2026-07-10T14:12:30.123Z'.
  - `limit` (query) — number _(min=1; max=100)_
  - `cursor` (query) — string — Opaque cursor returned by a previous page; pass it back to fetch the next page. _(minLen=1; maxLen=2048)_
  - `filter` (query) — array — Audit event attribute equality filters, one `key=value` per entry.
- **Response 200** (`QueryAuditEventsResponseContent`)
  - `events` — array **(required)**
    - _array of_ `AuditEvent`
      - `eventId` — string **(required)** — Opaque audit event identifier generated by the audit service. _(minLen=1; maxLen=128)_
      - `timestamp` — string **(required)** — ISO-8601 timestamp with millisecond precision, e.g. '2026-07-10T14:12:30.123Z'.
      - `actor` — Actor **(required)** — Who performed an action: an interactive user, an API key or an internal service.
        - `type` — string **(required)** _(enum: `user`, `api_key`, `service`)_
        - `id` — string **(required)** — User id, API key id or service name, depending on the actor type.
        - `name` — string — Human readable name of the actor at the time of the action.
      - `action` — string **(required)** — Normalized action, e.g. 'created', 'updated', 'published' or 'deleted'.
      - `resource` — string **(required)** — Canonical URI of the audited resource, e.g. 'wilma://agents/UXDT1W9fI3sj' or 'wilma://skills/aB3dE5fG7hJ9'. Carries the owning service and entity kind in its path. _(pattern=^[a-z][a-z0-9+.-]*://.+$; minLen=1; maxLen=512)_
      - `attributes` — AttributesMap — Expandable key/value data used for filtering and display.
      - `changes` — array — Field-level before/after values. Present for configuration changes; omitted for lifecycle events with no field diff.
        - _array of_ `AuditChange`
          - `path` — string **(required)** — JSON pointer of the changed field within the resource definition, e.g. '/engine/ai/instructions'.
          - `before` — any — Value before the change. Absent when the field was added.
          - `after` — any — Value after the change. Absent when the field was removed.
  - `nextCursor` — string — Opaque cursor returned by a previous page; pass it back to fetch the next page. _(minLen=1; maxLen=2048)_
- Errors: `400`

### References

#### `GET` `/v2/audit/references`

Returns the resources that reference the given entity — where it is used. Only the current
    surface of each referrer is considered: its draft and its latest published version; references
    present only in a draft are flagged on the returned entry. An entity nothing references (or an
    unknown uri) yields an empty list.

- operationId: `QueryReferences`
- **Scopes**: `wilma-audit:QueryReferences`, `wilma-audit:read`
- **Parameters**
  - `company` (query) — string _(minLen=3; maxLen=30)_
  - `uri` (query) — string **(required)** — The entity to find references to, e.g. 'wilma://skills/aB3dE5fG7hJ9'. _(pattern=^[a-z][a-z0-9+.-]*://.+$; minLen=1; maxLen=512)_
  - `limit` (query) — number _(min=1; max=100)_
  - `cursor` (query) — string — Opaque cursor returned by a previous page; pass it back to fetch the next page. _(minLen=1; maxLen=2048)_
- **Response 200** (`QueryReferencesResponseContent`)
  - `references` — array **(required)**
    - _array of_ `Reference`
      - `uri` — string **(required)** — Canonical URI of the referencing resource, e.g. 'wilma://agents/UXDT1W9fI3sj'. Carries '?draft' when the reference exists only in the referrer's draft. _(pattern=^[a-z][a-z0-9+.-]*://.+$; minLen=1; maxLen=512)_
      - `label` — string **(required)** — Human-readable name of the referencing resource at query time, e.g. the agent name. Postfixed with ' (Draft)' for draft-only references.
  - `nextCursor` — string — Opaque cursor returned by a previous page; pass it back to fetch the next page. _(minLen=1; maxLen=2048)_
- Errors: `400`
